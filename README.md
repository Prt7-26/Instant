# Instant

Instant 是一款轻巧的 macOS 菜单栏 AI 助手。按下快捷键即可唤出玻璃浮层，随时提问、追问或翻译，用完即可收起，继续手头的工作。

- **随时唤起**：默认使用 `⌥ Space` 呼出或收起，支持自定义快捷键。
- **连续问答**：回答逐步显示，支持结合当前对话继续追问；收起后保留会话和草稿。
- **双语翻译**：空输入时双击空格切换翻译模式，支持单词释义、例句及段落翻译。
- **联网搜索**：使用支持搜索的阿里云千问服务时，可获取实时信息，并查看回答来源。
- **一键复制**：每条回答都可单独复制，生成中的内容也可复制。
- **本地归档**：对话保存为 Markdown 文件，支持手动归档、自动归档和自定义保存位置。
- **多语言**：支持 30 种界面与回答语言，默认跟随系统。
- **自选模型**：可配置自己的模型服务，API Key 保存在 macOS 钥匙串中。

适用于 macOS 26 及更新版本。首次使用时，在设置中填写服务地址、API Key 和模型即可开始。
