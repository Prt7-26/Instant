Instant

需要 macOS 26 或更新版本，请下载适合自己 Mac 芯片的安装包。

安装：将 Instant.app 拖入 Applications，然后从“应用程序”打开。
更新：先退出正在运行的 Instant，再拖入新版并替换旧版。

当前直接分发包没有 Apple Developer ID 签名和公证，首次打开可能被 macOS 拦截。
请确认下载来源；Apple 对相关提示的说明：https://support.apple.com/102445

⌥ Space 呼出；Enter 提问；空输入时双击空格切换翻译；⌘ , 打开设置。
菜单栏星形图标右键可打开设置或退出。

首次使用需填写自己的 Base URL、API Key 和模型；模型服务可能另行收费。
API Key 保存在本机钥匙串，设置与归档存放在应用包之外，替换应用不会主动删除它们。
本版本尚未接入自动更新，请从发布者的下载页面获取新版。
